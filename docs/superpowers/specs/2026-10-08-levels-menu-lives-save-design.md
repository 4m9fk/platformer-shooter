# Уровни, меню, жизни и сохранение: дизайн

Дата: 2026-10-08. Статус: согласован в обсуждении, ждёт ревью.
Основа: первая версия по спеке `2026-10-06-platformer-shooter-design.md`.

## 1. Цель

Превратить один уровень в короткую игру для ребёнка: пять уровней с растущей
сложностью, меню выбора уровня, три жизни на попытку, звёзды за прохождение,
прогресс переживает закрытие приложения.

Решения пользователя:

- Жизни кончились → уровень начинается заново с полным запасом жизней.
  Открытые уровни и звёзды не теряются.
- Уровни открываются по порядку; на каждый пройденный уровень сохраняется
  лучший результат 1–3 звезды, звёзды видны в меню.
- Пять карт из существующих объектов (`# = C Z P F`), новых механик нет.
- Меню выбора уровня при запуске, пауза в игре, экран победы с «Дальше».

Не входит: сохранение внутри уровня, общий счёт, сброс прогресса из
интерфейса, синхронизация между устройствами, звук, новые объекты на картах.

## 2. Экраны и сцены

Порядок сцен: `Boot` → `Menu`. Нажатие на открытый уровень: `Menu`
останавливается, стартует `Game` с данными `{ level: i }` и запускается `UI`.
«В меню»: `Game` и `UI` останавливаются, стартует `Menu`. «Заново»:
`Game.scene.restart({ level: i })`. «Дальше»: то же с `i + 1`.

### MenuScene (новая)

- Фон: небо и холмы темы первого уровня, без камеры и без параллакса.
- Заголовок «Platformer Shooter» сверху по центру.
- Ряд из пяти плиток по центру экрана. Плитка: квадрат со скруглением, номер
  уровня крупно, под ним три звезды (закрашенные по сохранённому результату,
  остальные контуром). Закрытый уровень серый, вместо номера замок, на
  нажатие не реагирует.
- Раскладка: новая функция `menuLayout(width, height, insets)` в
  `ui/layout.ts`, плитки внутри безопасной зоны и по центру расширенного
  `EXPAND` экрана.
- Оверлей «Поверни телефон» есть и здесь. Логика ориентации (проверка
  `innerHeight > innerWidth`, подписка на `resize`/`orientationchange`,
  отписка на `SHUTDOWN`) выносится из `UIScene` в `ui/orientation.ts` и
  используется обеими сценами; пауза `Game` при портретной ориентации
  остаётся в `UIScene`.

### UIScene (расширяется)

- Сердечки жизней слева сверху рядом со счётчиком зомби: `LIVES` штук,
  потерянные полупрозрачные. Место задаёт `hudLayout` (новое поле `lives`).
- Кнопка ⏸ справа сверху рядом с ⛶ (поле `pause` в `hudLayout`); видна и без
  тача. Клавиша Esc делает то же. Нажатие ставит `Game` на паузу и
  показывает оверлей «Пауза»: «Продолжить», «Заново», «В меню».
- Оверлей «Победа!»: звёзды появляются по одной с интервалом `STAR_DELAY`,
  кнопки «Дальше», «Заново», «В меню». На последнем уровне вместо «Дальше»
  строка «Все уровни пройдены!».
- Оверлей «Попробуй ещё раз»: кнопки «Заново», «В меню».
- Все три оверлея собираются одной фабрикой `makeOverlay(title, buttons)`:
  затемнение на весь экран, заголовок, ряд кнопок. Нынешний `makeWinScreen`
  заменяется ею.
- Пока виден любой оверлей, тач-кнопки управления скрыты и ⏸ не работает.

### Связь Game и UI

Как сейчас: `UI` каждый кадр читает `registry`, `Game` пишет. Поля:

| Поле | Кто пишет | Значение |
|---|---|---|
| `levelIndex` | Game.create | индекс в `LEVELS` |
| `kills`, `zombiesTotal` | Game | как сейчас |
| `lives` | Game | от `LIVES` до 0 |
| `result` | Game | `null`, `'won'`, `'lost'` (заменяет `won`) |
| `stars` | Game при победе | 1–3 |

`paused` не хранится: `UI` сама знает, что показала паузу.

### Смерть и победа в GameScene

- Смерть (касание зомби сбоку или падение в яму): `lives` уменьшается на 1.
  Если жизни остались, работает текущий `respawn` (мигание, затемнение,
  старт уровня; зомби и ящики не восстанавливаются). Если 0, герой замирает,
  `result = 'lost'`, физика `Game` ставится на паузу после затемнения.
- Победа (флаг): `stars = starsFor(...)`, прогресс обновляется через
  `recordWin` и сохраняется, `result = 'won'`.
- `livesLost = LIVES - lives` на момент победы.

## 3. Данные

Три модуля без Phaser.

### levels/levels.ts

```ts
export interface Theme { skyTop: number; skyBottom: number; hillsFar: number; hillsNear: number }
export interface LevelDef { id: string; map: string[]; theme: Theme }
export const LEVELS: LevelDef[];
```

- Карты в `levels/maps/level1.ts` … `level5.ts`, каждая экспортирует
  `string[]`. Нынешний `levels/level1.ts` переезжает туда без изменений.
- `id`: `'level-1'` … `'level-5'`. Прогресс привязан к `id`.
- Темы: `DAY` (текущие цвета из `config.ts` и `placeholders.ts`), `SUNSET`,
  `DUSK`. Уровни 1–2 день, 3–4 закат, 5 сумерки.
- `textures/placeholders.ts`: небо и холмы выносятся в
  `makeBackdrop(scene, key, theme)`, текстуры `sky-<key>`, `hills-far-<key>`,
  `hills-near-<key>`. `GameScene` и `MenuScene` создают их, если ключа ещё
  нет в `textures`. Облака, земля, ящики, флаг, снаряд общие.
- `SKY_TOP`/`SKY_BOTTOM` в `config.ts` остаются только как цвет фона
  `Phaser.Game` до загрузки и равны теме `DAY`.

### game/stars.ts

```ts
export function starsFor(r: { kills: number; zombiesTotal: number; livesLost: number }): 1 | 2 | 3
```

1 за прохождение, +1 если `kills >= zombiesTotal`, +1 если `livesLost === 0`.

### game/progress.ts

```ts
export type Progress = { stars: Record<string, number> };
export function isUnlocked(p: Progress, levels: { id: string }[], index: number): boolean;
export function recordWin(p: Progress, id: string, stars: number): Progress;
export function loadProgress(storage: Storage | undefined): Progress;
export function saveProgress(storage: Storage | undefined, p: Progress): void;
```

- `isUnlocked`: индекс 0 всегда открыт; индекс `i` открыт, если у
  `levels[i - 1].id` есть звёзды.
- `recordWin` возвращает новый объект, звёзды `max(старые, новые)`.
- Ключ `localStorage`: `platformer-shooter.progress`, значение
  `{"v":1,"stars":{"level-1":3}}`.
- Сбои: исключение при доступе к `localStorage` (приватный режим, запрет)
  → `loadProgress` возвращает пустой прогресс, `saveProgress` ничего не
  делает. Нечитаемый JSON или `v !== 1` → пустой прогресс. Значение не целое
  1–3 → эта запись отбрасывается.
- Сцены получают хранилище через функцию `safeStorage()`, которая возвращает
  `window.localStorage` или `undefined`, если сам доступ бросает исключение.

### config.ts

`LIVES = 3`, `STAR_DELAY = 300`.

## 4. Карты

Все карты 9 строк. Правила из первой карты: прыжок ~2 тайла вверх и ~2,8 в
сторону, ямы в нижнем ряду не шире 2 тайлов, платформы на 2 тайла выше
опоры, ящики под выстрел стоят по 2 в высоту, старт на земле.

| № | Тема | Ширина | Зомби | Особенность |
|---|---|---|---|---|
| 1 | день | 70 | 5 | текущая карта |
| 2 | день | 80 | 6 | ямы чаще, зомби у края ямы |
| 3 | закат | 90 | 7 | лестницы из платформ на два этажа, зомби наверху |
| 4 | закат | 100 | 8 | стены из ящиков под выстрел, за ними ямы |
| 5 | сумерки | 110 | 10 | всё вместе, флаг на верхней платформе |

Каждую новую карту проходит исполнитель в браузере с клавиатуры до флага;
непроходимое место правится в карте.

## 5. Тестирование

Vitest:

- `levels/levels.test.ts` (вместо `level1.test.ts`): каждая карта проходит
  `parseLevel`; `id` уникальны; ширины и число зомби по таблице §4; каждый
  зомби стоит на опоре; под `P` есть опора; в нижнем ряду нет ямы шире 2;
  у уровня 1 сохраняются прежние проверки (две высоты платформ, флаг выше
  старта).
- `game/stars.test.ts`: четыре сочетания (только прохождение, все зомби,
  без потерь, оба условия).
- `game/progress.test.ts`: уровень 0 открыт на пустом прогрессе; уровень 4
  закрыт, пока нет звёзд у уровня 3; `recordWin` не понижает; загрузка
  битого JSON, `v: 2`, значения `7` и `1.5`; хранилище, бросающее при
  `getItem` и `setItem`; круговой save → load.
- `ui/layout.test.ts`: `menuLayout` держит плитки в безопасной зоне на 960×540
  и на широком экране с вырезом; новые поля `hudLayout` (`lives`, `pause`)
  внутри безопасной зоны.

Ручная проверка (браузер и телефон):

1. Меню: открыт только уровень 1, остальные с замком.
2. Пройти уровень 1 без потерь со всеми зомби: три звезды, «Дальше» ведёт на
   уровень 2, в меню уровень 2 открыт.
3. Потерять три жизни: «Попробуй ещё раз», «Заново» даёт полные жизни и
   восстановленных зомби.
4. ⏸ и Esc: игра стоит, «Продолжить» возвращает, «В меню» выходит.
5. Пройти все пять уровней; на пятом «Все уровни пройдены!».
6. Закрыть и открыть PWA: звёзды и открытые уровни на месте.
7. Приватная вкладка Safari: игра работает, прогресс не запоминается.
8. Портрет в меню и в игре: «Поверни телефон».

## 6. Порядок работы

Ветка `levels-menu` от `prototype`. Слияние в `main` (и деплой) только с
подтверждения пользователя.

1. `stars.ts`, `progress.ts` с тестами.
2. `levels.ts`, перенос карты 1, темы, `makeBackdrop`, `GameScene.init({ level })`.
3. Жизни в `GameScene`, `result` вместо `won`.
4. Фабрика оверлеев, сердечки, ⏸, победа со звёздами, поражение.
5. `orientation.ts`, `MenuScene`, `menuLayout`, Boot → Menu.
6. Карты 2–5 с тестами и проходом в браузере.
